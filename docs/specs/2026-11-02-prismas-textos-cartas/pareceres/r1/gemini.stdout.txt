#### [P1] Untyped Array Reassignment in `_wrap_topic`
* **File & Lines**: [scripts/ui/upgrade_card.gd:206, 214](file:///C:/Users/danie/Documents/ChatGPT/TEC%20-%20Jogos/scripts/ui/upgrade_card.gd#L206-L214)
* **Source Evidence**:
  ```gdscript
  var content_colors: Array[Color] = []
  ...
  if needs_space and content.length() + 1 + word.length() > TOPIC_CONTENT_WIDTH:
      result.append(_make_topic_line(content, content_colors, result.is_empty()))
      content = word
      content_colors = [] # <-- REASSIGNS UNTYPED ARRAY TO Array[Color]
  ```
* **Impact**: In Godot 4 GDScript, `[]` is a generic `Array` (`Array[Variant]`). Assigning `[]` to `content_colors: Array[Color]` re-triggers the exact engine warning/error logged for `_make_topic_line`: `Trying to assign an array of type 'Array' to a variable of type 'Array[Color]'`.
* **Fix**: Replace `content_colors = []` with `content_colors.clear()`.
