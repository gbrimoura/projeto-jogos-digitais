#### P2 (Defensive Edge Cases & Hardening)
1. **Bootstrap Lifecycle Guard (`target_panel.gd`)**:
   - *Source Evidence*: Lines `@onready var _name_text = $NameText`, etc., inside `set_target()` / `clear_target()`.
   - *Condition*: If `clear_target()` or `set_target()` is called during scene initialization before `Target` has completed `_ready()`, calling `.call("set_text", ...)` on `@onready` variables will encounter `null` instances.
   - *Mitigation*: Add an early exit guard: `if not is_node_ready(): return` or check `if _name_text == null: return`.
2. **Division by Zero Protection on Broken Textures (`_set_portrait`)**:
   - *Source Evidence*: `PORTRAIT_REGION.x / natural_size.x` and `PORTRAIT_REGION.y / natural_size.y`.
   - *Condition*: If a dynamic or corrupted texture is passed with $w \le 0$ or $h \le 0$, floating point division by zero occurs.
   - *Mitigation*: Add `if natural_size.x <= 0.0 or natural_size.y <= 0.0: return` before calculating `contain_scale`.
3. **Empty / Null Display Name Fallback in Bridge (`BRIDGE_UPDATE_TARGET`)**:
   - *Source Evidence*: `var target_name: String = String(nearest.get("display_name"))`.
   - *Condition*: If an enemy node lacks the `display_name` property or returns an empty variant, `target_name` becomes empty or `"<null>"`.
   - *Mitigation*: Fall back to `nearest.name` if `target_name.strip_edges().is_empty()`.
