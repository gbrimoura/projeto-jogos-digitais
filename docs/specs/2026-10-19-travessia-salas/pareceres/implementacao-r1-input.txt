# Plano — travessia e transição entre salas

**19/10/2026 · R3 prospectivo; contrato autorizado após revisão arquitetural.**

## Objetivo e base

Após clear, recompensa local e guard, o jogador atravessa a saída lateral andando para a direita, sem E. Manter a entrada fechada, HP/build, morte/restart e terminal. R3 incorpora o delta do principal em `pareceres/plano-r3-delta-input.txt` e README de pareceres; R1/R2 estão preservados em `historico/`. Fonte: docs/README, AGENTS, planos/specs de porta lateral, geração e game loop, GDD §3.

## Decisões executáveis

- RightWall superior/inferior: 64×432 em (1120,216) e 64×88 em (1120,604); gate 64×128 em (1120,496); RightOuterGuard 8×648 em (1156,324), todos como shapes de `WorldCollision`. Gate começa sólido, abre por `set_deferred(disabled=true)` após clear+recompensa local+guard, nunca é freed. Validador confere nomes/geometrias sem depender do disabled já aplicado; guard mantém retry dentro do mapa.
- ExitDoor amostra Player conhecido da mesma sala em todo physics frame, independentemente de sinais/overlaps de Area. Usa centro real do `CollisionShape2D` transformado para a porta; Player.origin é os pés (y=560), não o centro (y=522). Cruza se `previous_x < 1120 <= current_x`, `current_x > previous_x`, e centro dentro do vão. No unlock, amostra é inicializada em current; retry standalone rearma somente após recuar abaixo de 1120. Revalidação deferred usa latch do cruzamento e geometria atual, nunca exige Area overlap ou velocidade positiva final.
- Só após revalidar source/state/player viva/clear/local reward/guard/gate/latch/yx, Main salva `disable_mode` e `process_mode`, define `KEEP_ACTIVE` antes de `PROCESS_MODE_DISABLED`, zera velocity e prossegue. Rollback restaura process_mode antes do disable_mode; gate fica aberto e retry requer recuo/recruzamento.
- Managed: RunController, único dono de fade, recebe a saída, oferece a recompensa de chefe existente após o cruzamento e anima antes de substituir sala; nova instância Player/HP/build segue o fluxo atual. Standalone: helper CanvasLayer root `PROCESS_MODE_ALWAYS`, sem pausar SceneTree, controla token, fade ~180/220 ms e troca. Snapshot HP/build só é preparado no preto, imediatamente antes do swap, após source=current_scene e token válidos. Main não aguarda após swap legítimo.
- Helper espera nova current_scene pronta, até120 frames, cancela limpo em death/restart/owner obsoleto, limpa snapshot/revela cena existente se o swap falhar; Main._exit_tree normal de swap não cancela snapshot/helper. Pause/reset UI é bloqueada durante busy. Managed pausa só se for dona, sem despausar GameOver/vitória.
- Terminal standalone sem destino é decidido antes do unlock: gate permanece sólido, `ETAPA CONCLUÍDA`. Retry só existe em standalone; managed failure segue GameOver/restart e não reapresenta/reaplica recompensa de chefe.

# Especificação — travessia física e transição entre salas

**R3 · 19/10/2026 · Contrato de implementação; ainda sem runtime nesta gravação.**

## Geometria e gate

Em ambas as fixtures, `WorldCollision` recebe shapes direitos: `RightWallUpper` centro (1120,216), size64×432; `RightWallLower` (1120,604), 64×88; `ExitGate` (1120,496), 64×128; `RightOuterGuard` (1156,324), 8×648. O vão segue x=[1088,1152), y=[432,560); o piso mantém topo560 e width1152. LeftWall continua sólido. Gate inicia ativo, é aberto por `set_deferred("disabled", true)` após liberação local e nunca é removido. O validador exige nós/dimensões/transform independentes do estado disabled; `_collect_authored_world_obstacles` segue considerando shapes ativos, guard é exterior e não afeta spawns/patrulha. Em terminal standalone o gate não abre.

## Amostragem e lock

ExitDoor (sem depender de `body_entered`/`get_overlapping_bodies`) consulta o Player da mesma sala a cada physics frame. Centro do collider: transformar `CollisionShape2D.shape.get_rect().get_center()` pelo `global_transform` da shape e depois para coordenadas locais da porta. Não usar Player.global_position.y: é o pé em y560, enquanto o centro está em y522 no piso. Linha de saída x=1120 local/global conforme transform da sala; y e x devem estar no retângulo do vão.

A primeira amostra só inicializa histórico. Cruzamento latch quando `previous_x < line_x && current_x >= line_x && current_x > previous_x`, centro atual dentro do vão, saída unlocked e não busy. Não exigir velocity final: colisão com OuterGuard pode zerá-la no mesmo frame. Unlock inicializa `previous=current` e arma só se jogador ainda está antes da linha. Após rollback standalone, desarmar até centro recuar para x<line, então atualizar amostra; nova tentativa exige cruzá-la de novo. Managed não faz retry.

Door emite evento latched; Main faz `call_deferred` e antes de lock revalida token, sala fonte ativa, `EXIT_RELEASED`, clear, oferta local concluída, guard off, jogador correto/vivo, gate liberado, latch e geometria atual no vão além da linha. Revalidação é geométrica, sem consultar overlap da Area nem repetir a condição previous<line. No sucesso: gravar `Player.disable_mode` e `process_mode`; set `disable_mode=KEEP_ACTIVE` antes de `process_mode=DISABLED`; zerar velocity. Em rollback: restaurar process_mode primeiro, depois disable_mode original; gate aberto. Pause/reset UI bloqueada enquanto busy. Morte/restart cancela token e helper; normal `_exit_tree` de Main no swap esperado não limpa snapshot.

## Fade, swap e recuperação

Overlay CanvasLayer único, layer acima do HUD, `PROCESS_MODE_ALWAYS`, transparente não captura mouse. Fade alpha0→1 ~180ms, swap em preto, alpha1→0 ~220ms. Standalone nunca modifica `SceneTree.paused`. Carregar PackedScene antes do fade; snapshot HP atual/máximo+Build é criado só no preto, logo antes do swap, se token válido e `tree.current_scene == source`. Helper fica na raiz (não Main), valida dono/token; depois do swap espera `current_scene != source`, válida e ready, até120 `process_frame`s. Sucesso revela nova sala e se libera. Erro imediato limpa snapshot, revela antiga e rollback/retry. Se source já saiu mas nova cena não fica ready, limpar snapshot, revelar o que existir e destruir overlay; sem preto permanente. Cancelamento de Tween/overlay em death/restart não pode deixar await pendurado; token/timer cancelável sempre termina cleanup.

Managed: RunController é dono do fade, mantém pause ownership, resolve RewardScreen de chefe existente após cruzamento e só depois troca para sala PackedScene nova. Nunca reutiliza Player nem RoomTransition snapshot; permanece HP/build atuais. Após cada await, revalidar `_run_ended` e sala concluída ainda atual. Se for dona da pausa, só despausa em sucesso normal; GameOver/vitória ficam pausados e visíveis. Falha managed revela erro e segue GameOver/restart, sem retry/recompensa duplicada. Standalone sem destino decide terminal antes de unlock: gate fechado, `ETAPA CONCLUÍDA`.

## Escopo e aceite

Alterar apenas 7 runtime: `exit_door.gd/.tscn`, `main.gd`, `run_controller.gd`, novo `room_transition_overlay.gd`, `main.tscn`, `second_room.tscn`; não editar RoomTransition sem necessidade comprovada. Aceite estático: shapes/validador corretos; gate depende de clear/recompensa local/guard; entrada fechada; cruzamento geométrico +X único; E/proximidade não transita; rollback precisa recuo/recruzamento; snapshot só em swap standalone válido; managed mantém boss reward/HP/build e nova instância; terminal fechado; cancel/restart/death sem tela preta, pause ou lock órfãos. Sem Godot/import/testes/QA. Arte, Player/movement, piso, spawn, gerador, inimigos, resources, imports, project/plugin/settings e Git ficam intactos.

extends Area2D

## Saída lateral aberta pela sala; o jogador a atravessa andando para a direita.

signal transition_requested(player: Player)

@export_enum("Exit", "Entrance") var door_role: int = 0
@export var player_path: NodePath = NodePath("../Player")
@export var gate_path: NodePath = NodePath("../WorldCollision/ExitGate")

@onready var _door_visual: Node2D = $SideDoorVisual
@onready var _door_label: Label = $DoorLabel

var _room_root: Node2D
var _player: Player
var _gate: CollisionShape2D
var _room_is_cleared: bool = false
var _transition_busy: bool = false
var _terminal_complete: bool = false
var _retry_enabled: bool = true
var _failure_message: String = ""
var _sample_initialized: bool = false
var _previous_center_room := Vector2.ZERO
var _crossing_armed: bool = false
var _crossing_latched: bool = false
var _latched_player: Player

func _ready() -> void:
	_room_root = get_parent() as Node2D
	_player = get_node_or_null(player_path) as Player
	_gate = get_node_or_null(gate_path) as CollisionShape2D
	if _gate != null:
		_gate.set_deferred("disabled", false)
	_update_presentation()

func _physics_process(_delta: float) -> void:
	if door_role != 0 or _player == null or not is_instance_valid(_player):
		return
	var center := _player_collider_center_in_room(_player)
	if center == null:
		return
	var current_center: Vector2 = center
	if not _sample_initialized:
		_previous_center_room = current_center
		_sample_initialized = true
		return

	var line_x := _exit_line_x_in_room()
	if not _crossing_armed and current_center.x < line_x:
		_crossing_armed = true
		_failure_message = ""
		_update_presentation()

	if _room_is_cleared and not _transition_busy and not _crossing_latched \
		and _crossing_armed and _previous_center_room.x < line_x \
		and current_center.x >= line_x and current_center.x > _previous_center_room.x \
		and _point_is_inside_exit_opening(current_center):
		_crossing_latched = true
		_crossing_armed = false
		_latched_player = _player
		_transition_busy = true
		_failure_message = ""
		_update_presentation()
		transition_requested.emit(_player)

	_previous_center_room = current_center

func set_room_cleared(cleared: bool) -> void:
	if door_role != 0 or _terminal_complete:
		return
	_room_is_cleared = cleared
	if _gate != null:
		# A cleared exit is a traversable hole; rollback keeps it open for retry.
		_gate.set_deferred("disabled", cleared)
	if not cleared:
		_transition_busy = false
		_failure_message = ""
		_crossing_latched = false
		_latched_player = null
		_crossing_armed = false
		_sample_initialized = false
	elif _player != null and is_instance_valid(_player):
		var center := _player_collider_center_in_room(_player)
		if center != null:
			_previous_center_room = center
			_sample_initialized = true
			_crossing_armed = center.x < _exit_line_x_in_room()
	_update_presentation()

func set_transition_busy(busy: bool) -> void:
	if door_role != 0 or _terminal_complete:
		return
	if busy and not _room_is_cleared:
		return
	_transition_busy = busy
	if busy:
		_failure_message = ""
	_update_presentation()

func set_retry_enabled(enabled: bool) -> void:
	_retry_enabled = enabled

func report_transition_failure(message: String) -> void:
	if door_role != 0 or _terminal_complete:
		return
	_failure_message = message.strip_edges()
	_crossing_latched = false
	_latched_player = null
	_crossing_armed = false
	if _retry_enabled:
		_transition_busy = false
		# A retry stays disarmed until the collider center retreats below the line.
	else:
		_transition_busy = true
	_update_presentation()

func has_latched_crossing(player: Player) -> bool:
	return (
		door_role == 0
		and _room_is_cleared
		and _transition_busy
		and _crossing_latched
		and player != null
		and is_instance_valid(player)
		and player == _latched_player
		and _player == player
	)

func is_player_inside_exit_opening(player: Player) -> bool:
	if player == null or not is_instance_valid(player) or player != _player:
		return false
	var center := _player_collider_center_in_room(player)
	return center != null and _point_is_inside_exit_opening(center)

func is_gate_open() -> bool:
	return _gate != null and not _gate.disabled

func set_terminal_complete() -> void:
	_terminal_complete = true
	_room_is_cleared = false
	_transition_busy = false
	_failure_message = ""
	_crossing_latched = false
	_latched_player = null
	_crossing_armed = false
	if _gate != null:
		_gate.set_deferred("disabled", false)
	_update_presentation()

func _player_collider_center_in_room(player: Player) -> Variant:
	if _room_root == null or not is_instance_valid(_room_root):
		return null
	var collision := player.get_node_or_null("CollisionShape2D") as CollisionShape2D
	if collision == null or collision.shape == null:
		return null
	var center_global := collision.global_transform * collision.shape.get_rect().get_center()
	return _room_root.to_local(center_global)

func _exit_line_x_in_room() -> float:
	if _gate == null or _room_root == null:
		return 1120.0
	return _room_root.to_local(_gate.global_position).x

func _point_is_inside_exit_opening(center_room: Vector2) -> bool:
	if _gate == null or _room_root == null or _gate.shape == null:
		return false
	var gate_to_room := _room_root.global_transform.affine_inverse() * _gate.global_transform
	var opening := _transform_rect(_gate.shape.get_rect(), gate_to_room)
	return opening.has_point(center_room)

func _transform_rect(rect: Rect2, transform: Transform2D) -> Rect2:
	var a := transform * rect.position
	var b := transform * Vector2(rect.end.x, rect.position.y)
	var c := transform * rect.end
	var d := transform * Vector2(rect.position.x, rect.end.y)
	var minimum := Vector2(
		minf(minf(a.x, b.x), minf(c.x, d.x)),
		minf(minf(a.y, b.y), minf(c.y, d.y))
	)
	var maximum := Vector2(
		maxf(maxf(a.x, b.x), maxf(c.x, d.x)),
		maxf(maxf(a.y, b.y), maxf(c.y, d.y))
	)
	return Rect2(minimum, maximum - minimum)

func _update_presentation() -> void:
	if not is_instance_valid(_door_visual) or not is_instance_valid(_door_label):
		return
	if door_role != 0:
		_door_visual.call("set_aperture_open", false)
		_door_label.text = "ENTRADA\nACESSO BLOQUEADO"
		return
	if _terminal_complete:
		_door_visual.call("set_aperture_open", false)
		_door_label.text = "ETAPA CONCLUÍDA"
		return

	var is_open := _room_is_cleared
	_door_visual.call("set_aperture_open", is_open)
	if _transition_busy:
		_door_label.text = "TRANSIÇÃO EM CURSO"
	elif not _room_is_cleared:
		_door_label.text = "SAÍDA BLOQUEADA\nELIMINE OS INIMIGOS"
	elif not _failure_message.is_empty():
		_door_label.text = "%s\nRECUE E TENTE NOVAMENTE" % _failure_message
	else:
		_door_label.text = "SAÍDA ABERTA\nATRAVESSE"

func _validate_authored_platform(
	platform: SolidPlatform,
	expected_position: Vector2,
	expected_size: Vector2
) -> Dictionary:
	if platform.position.distance_to(expected_position) > 0.01:
		return {"valid": false, "error": "%s fora da posição autoral" % platform.name}
	if platform.size.distance_to(expected_size) > 0.01:
		return {"valid": false, "error": "%s fora do tamanho autoral" % platform.name}
	if platform.randomize_position or platform.randomize_width:
		return {"valid": false, "error": "%s ainda permite aleatoriedade" % platform.name}
	if absf(platform.rotation) > 0.001 or not platform.scale.is_equal_approx(Vector2.ONE):
		return {"valid": false, "error": "%s tem transform autoral incompatível" % platform.name}

	var collision := platform.get_node_or_null("CollisionShape2D") as CollisionShape2D
	if collision == null or collision.disabled:
		return {"valid": false, "error": "%s sem CollisionShape2D ativo" % platform.name}
	var rectangle := collision.shape as RectangleShape2D
	if rectangle == null or rectangle.size.distance_to(expected_size) > 0.01:
		return {"valid": false, "error": "%s tem shape diferente do tamanho autoral" % platform.name}
	if collision.position.length() > 0.01 or absf(collision.rotation) > 0.001 or not collision.scale.is_equal_approx(Vector2.ONE):
		return {"valid": false, "error": "%s tem shape fora da origem local" % platform.name}
	return {"valid": true, "rect": Rect2(platform.position - expected_size * 0.5, expected_size)}

				continue
			if collision.shape == null:
				return _fail_authored_layout("shape ausente em %s" % body.name)
			found_shape = true
			_authored_world_obstacles.append({
				"owner": body,
				"rect": _collision_shape_aabb_in_main(collision),
			})
		if not found_shape:
			return _fail_authored_layout("nenhum shape ativo em World layer 1: %s" % body.name)
	return true

func _validate_authored_spawns_and_patrol() -> bool:
	var player_body := get_node_or_null("Player") as CollisionObject2D
	var player_spawn := get_node_or_null("PlayerSpawnMarker") as Marker2D
	if player_body == null or player_spawn == null:
		return _fail_authored_layout("spawn do jogador ausente")
	var player_bounds_result: Dictionary = _body_aabb(player_body, false)
	if not bool(player_bounds_result.get("valid", false)):
		return _fail_authored_layout("collider do jogador ausente")
	var player_bounds: Rect2 = player_bounds_result.get("rect", Rect2())
	var player_spawn_offset: Vector2 = player_spawn.position - player_body.position
	player_bounds = Rect2(player_bounds.position + player_spawn_offset, player_bounds.size)
	if not _validate_clear_of_world_layer(player_bounds, "spawn do jogador"):
		return false

	var worker_body := get_node_or_null("RivetWorker") as CollisionObject2D
	var patrol_area := get_node_or_null("WorkerPatrolArea") as Node2D
	if worker_body == null or patrol_area == null:
		return _fail_authored_layout("spawn ou patrulha do worker ausente")
	var worker_bounds_result: Dictionary = _body_aabb(worker_body, false)
	var worker_local_result: Dictionary = _body_aabb(worker_body, true)
	if not bool(worker_bounds_result.get("valid", false)) or not bool(worker_local_result.get("valid", false)):
		return _fail_authored_layout("collider do worker ausente")
	var worker_bounds: Rect2 = worker_bounds_result.get("rect", Rect2())
	var worker_local_bounds: Rect2 = worker_local_result.get("rect", Rect2())
	if not _validate_clear_of_world_layer(worker_bounds, "spawn do worker"):
		return false

	var left_limit := patrol_area.get_node_or_null("LeftLimit") as Marker2D
	var right_limit := patrol_area.get_node_or_null("RightLimit") as Marker2D
	if left_limit == null or right_limit == null:
		return _fail_authored_layout("limites de patrulha ausentes")
	var left_center: Vector2 = _local_transform_to_main(left_limit) * Vector2.ZERO
	var right_center: Vector2 = _local_transform_to_main(right_limit) * Vector2.ZERO
	var minimum_center_x := minf(left_center.x, right_center.x)
	var maximum_center_x := maxf(left_center.x, right_center.x)
	var sweep_bounds := Rect2(
		Vector2(minimum_center_x + worker_local_bounds.position.x, worker_body.position.y + worker_local_bounds.position.y),
		Vector2(maximum_center_x - minimum_center_x + worker_local_bounds.size.x, worker_local_bounds.size.y)
	)
	if sweep_bounds.position.x < 64.0 or sweep_bounds.end.x > 1088.0:
		return _fail_authored_layout("patrulha do worker cruza as faces internas das paredes")
	return _validate_clear_of_world_layer(sweep_bounds, "intervalo de patrulha do worker")

func _validate_authored_target(platform_rects: Dictionary) -> bool:
	var target := get_node_or_null("TrainingTarget") as TrainingTarget
	if target == null or not target.authored_support_enabled:
		return _fail_authored_layout("TrainingTarget não está no modo de suporte autoral")
	if target.collision_layer != 8:
		return _fail_authored_layout("TrainingTarget deve permanecer na collision layer 8")
	var player_body := get_node_or_null("Player") as CollisionObject2D
	if player_body == null or player_body.collision_mask != 9:
		return _fail_authored_layout("Player deve manter collision_mask 9 para World e TrainingTarget vivo")
	var target_local_result: Dictionary = _body_aabb(target, true)
	if not bool(target_local_result.get("valid", false)):
		return _fail_authored_layout("collider do TrainingTarget ausente")
	var target_local_bounds: Rect2 = target_local_result.get("rect", Rect2())
	if target.fixed_support_path.is_empty() or target.fallback_support_path.is_empty():
		return _fail_authored_layout("caminho de suporte autoral vazio")

	var support_paths: Array[NodePath] = [target.fixed_support_path, target.fallback_support_path]
	for support_path in support_paths:
		var support := _resolve_authored_support(target, support_path)
		if support == null or not platform_rects.has(support.name):
			continue
		var support_rect: Rect2 = platform_rects[support.name]
		if support_rect.size.x < target_local_bounds.size.x + AUTHORED_EDGE_MARGIN * 2.0:
			continue
		var target_origin := Vector2(
			support_rect.get_center().x - target_local_bounds.get_center().x,
			support_rect.position.y - target_local_bounds.end.y
		)
		var target_bounds: Rect2 = Rect2(target_local_bounds.position + target_origin, target_local_bounds.size)
		if target_bounds.position.x < support_rect.position.x + AUTHORED_EDGE_MARGIN - 0.01:
			continue
		if target_bounds.end.x > support_rect.end.x - AUTHORED_EDGE_MARGIN + 0.01:
			continue
		if absf(target_bounds.end.y - support_rect.position.y) > AUTHORED_CONTACT_TOLERANCE:
			continue
		if not _find_world_layer_overlap(target_bounds, support).is_empty():
			continue
		_authored_target_position = target_origin
		_authored_target_node = target
		return true

	return _fail_authored_layout("suportes primário e fallback do TrainingTarget são inválidos")

func _resolve_authored_support(target: TrainingTarget, path: NodePath) -> SolidPlatform:
	if target.get_parent() != self:
		return null
	var path_parts: PackedStringArray = String(path).split("/", false)
	if path_parts.size() != 2 or path_parts[0] != ".." or path_parts[1].is_empty():
		return null
	return get_node_or_null(NodePath(path_parts[1])) as SolidPlatform

func _validate_clear_of_world_layer(
	bounds: Rect2,
	label: String,
	allowed_support: CollisionObject2D = null
) -> bool:
	var blocker := _find_world_layer_overlap(bounds, allowed_support)
	if blocker.is_empty():
		return true
	return _fail_authored_layout("%s intersecta World layer 1 em %s" % [label, blocker])

func _find_world_layer_overlap(bounds: Rect2, allowed_support: CollisionObject2D = null) -> String:
	for obstacle_data: Dictionary in _authored_world_obstacles:
		var owner: CollisionObject2D = obstacle_data.get("owner") as CollisionObject2D
		if owner == null or owner == allowed_support:
			continue
		var obstacle_bounds: Rect2 = obstacle_data.get("rect", Rect2())
		if _positive_overlap_area(bounds, obstacle_bounds) > AUTHORED_OVERLAP_AREA_LIMIT:
			return String(owner.name)
	return ""

func _positive_overlap_area(first: Rect2, second: Rect2) -> float:
	var overlap_width := minf(first.end.x, second.end.x) - maxf(first.position.x, second.position.x)
	var overlap_height := minf(first.end.y, second.end.y) - maxf(first.position.y, second.position.y)
	if overlap_width <= 0.0 or overlap_height <= 0.0:
		return 0.0
	return overlap_width * overlap_height

func _body_aabb(body: CollisionObject2D, relative_to_body: bool) -> Dictionary:
	var found_shape := false
	var combined_bounds := Rect2()
	var body_transform := _local_transform_to_main(body)
	for shape_child in body.get_children():
		var collision := shape_child as CollisionShape2D
		if collision == null or collision.disabled or collision.shape == null:
			continue
		var shape_transform := _local_transform_to_main(collision)
		if relative_to_body:
			shape_transform = body_transform.affine_inverse() * shape_transform
		var shape_bounds := _transform_rect(collision.shape.get_rect(), shape_transform)
		if found_shape:
			combined_bounds = combined_bounds.merge(shape_bounds)
		else:
			combined_bounds = shape_bounds
			found_shape = true
	return {"valid": found_shape, "rect": combined_bounds}

func _collision_shape_aabb_in_main(collision: CollisionShape2D) -> Rect2:
	return _transform_rect(collision.shape.get_rect(), _local_transform_to_main(collision))

func _local_transform_to_main(node: Node2D) -> Transform2D:
	var transforms: Array[Transform2D] = []
	var current: Node = node
	while current != self:
		var current_2d := current as Node2D
		if current_2d == null:
			return Transform2D.IDENTITY
		transforms.append(current_2d.transform)
		current = current.get_parent()
		if current == null:
			return Transform2D.IDENTITY
	var result := Transform2D.IDENTITY
	for transform_index in range(transforms.size() - 1, -1, -1):
		result = result * transforms[transform_index]
	return result

func _transform_rect(rect: Rect2, transform: Transform2D) -> Rect2:
	var point_a := transform * rect.position
	var point_b := transform * Vector2(rect.end.x, rect.position.y)
	var point_c := transform * rect.end
	var point_d := transform * Vector2(rect.position.x, rect.end.y)
	var minimum_x := minf(minf(point_a.x, point_b.x), minf(point_c.x, point_d.x))
	var minimum_y := minf(minf(point_a.y, point_b.y), minf(point_c.y, point_d.y))
	var maximum_x := maxf(maxf(point_a.x, point_b.x), maxf(point_c.x, point_d.x))
	var maximum_y := maxf(maxf(point_a.y, point_b.y), maxf(point_c.y, point_d.y))
	return Rect2(minimum_x, minimum_y, maximum_x - minimum_x, maximum_y - minimum_y)

func _disable_invalid_authored_room() -> void:
	if player != null:
		player.process_mode = Node.PROCESS_MODE_DISABLED
	if combat_room != null:
		combat_room.process_mode = Node.PROCESS_MODE_DISABLED
	var target := get_node_or_null("TrainingTarget")
	if target != null:
		target.process_mode = Node.PROCESS_MODE_DISABLED
	var worker := get_node_or_null("RivetWorker")
	if worker != null:

	if exit_door != null:
		exit_door.call("set_room_cleared", false)

func _restart_authored_room() -> void:
	if _door_request_pending or _transition_in_progress or is_instance_valid(_transition_overlay):
		return
	_cancel_standalone_transition()
	get_tree().reload_current_scene()

func configure_run_managed(shared_build: RunBuild, offer_build_upgrade: bool, requested_seed: int = 0) -> bool:
	if is_inside_tree() or shared_build == null:
		return false
	var managed_exit_door := get_node_or_null("ExitDoor")
	if managed_exit_door == null or not managed_exit_door.has_signal("transition_requested"):
		return false
	if requested_seed != 0:
		room_layout_seed = requested_seed
	if authored_layout_enabled and not prepare_authored_layout():
		return false
	_run_controller_managed = true
	_managed_run_build = shared_build
	reward_enabled = offer_build_upgrade
	return true

func _ready() -> void:
	if authored_layout_enabled and not is_authored_layout_valid():
		_disable_invalid_authored_room()
		_show_authored_layout_error()
		return
	set_process_input(true)
	if not combat_room.room_cleared.is_connected(_on_room_cleared):
		combat_room.room_cleared.connect(_on_room_cleared)
	if player != null and not player.died.is_connected(_on_player_died):
		player.died.connect(_on_player_died)
	if exit_door != null:
		exit_door.call("set_retry_enabled", not _run_controller_managed)
		var transition_callback := Callable(self, "_on_exit_door_transition_requested")
		if not exit_door.is_connected("transition_requested", transition_callback):
			exit_door.connect("transition_requested", transition_callback)

	var title_label := get_node_or_null(room_title_label_path) as Label
	if title_label != null:
		title_label.text = room_title

	if player != null:
		player.reset_to_spawn(_get_player_spawn_position())

	# Os filhos já executaram _ready. O controlador mantém o estado da run
	# entre encontros; cenas standalone continuam consumindo o snapshot one-shot.
	var incoming_snapshot: Dictionary = {}
	if not _run_controller_managed:
		incoming_snapshot = RoomTransition.consume_pending_snapshot(_load_current_packed_scene())
	if _run_controller_managed and _managed_run_build != null:
		run_build = _managed_run_build
	else:
		run_build = RunBuild.new()
	if player != null:
		if not incoming_snapshot.is_empty() and player.health != null:
			var restored_build := RunBuild.new()
			if restored_build.replace_state(
				incoming_snapshot.get("upgrade_ids"),
				incoming_snapshot.get("counts_by_id")
			):
				var health_restored := player.health.restore_health_for_room_transition(
					int(incoming_snapshot["hp_current"]),
					int(incoming_snapshot["hp_max"])
				)
				if health_restored:
					run_build = restored_build
		player.apply_run_build(run_build)

	_upgrade_offer = UpgradeOfferScene.instantiate() as UpgradeOffer
	if _upgrade_offer != null:
		add_child(_upgrade_offer)
		_upgrade_offer.upgrade_selected.connect(_on_upgrade_selected)
		_upgrade_offer.hide()

	_update_build_status()
	if exit_door != null:
		exit_door.call("set_room_cleared", false)
	if combat_room.room_is_cleared:
		_on_room_cleared()

func _exit_tree() -> void:
	if _upgrade_offer != null and is_instance_valid(_upgrade_offer):
		_upgrade_offer.close_offer()
	if not _standalone_swap_committed:
		if is_instance_valid(_transition_overlay) and _transition_overlay.has_method("cancel_transition"):
			_transition_overlay.call("cancel_transition")
		if not _run_controller_managed and (_door_request_pending or _transition_in_progress):
			RoomTransition.clear_pending_snapshot()
	_guard_active = false
	_guard_waiting_for_release = false
	_guard_quiet_remaining = 0.0
	# Do not unpause during teardown; the new room inherits the actual tree state.
	_owned_offer_pause = false

func _input(event: InputEvent) -> void:
	if _door_request_pending or _transition_in_progress or is_instance_valid(_transition_overlay):
		if event.is_action_pressed(&"ui_cancel") or event.is_action_pressed(&"interact") \
			or (event is InputEventKey and (event as InputEventKey).keycode == KEY_R):
			get_viewport().set_input_as_handled()
			return
	if authored_layout_enabled and not is_authored_layout_valid():
		for action in DISCRETE_INPUT_ACTIONS:
			if event.is_action_pressed(action):
				get_viewport().set_input_as_handled()
				return
	if _upgrade_flow_state == UpgradeFlowState.OFFER_OPEN and event.is_action_pressed("interact"):
		get_viewport().set_input_as_handled()
		return
	if not _guard_active:
		return
	for action in DISCRETE_INPUT_ACTIONS:
		if event.is_action_pressed(action):
			_guard_waiting_for_release = true
			_guard_quiet_remaining = 0.0
			get_viewport().set_input_as_handled()
			return

func _process(delta: float) -> void:
	if not _guard_active:
		return
	if _any_discrete_input_pressed():
		_guard_waiting_for_release = true
		_guard_quiet_remaining = 0.0
		return
	if _guard_waiting_for_release:
		_guard_waiting_for_release = false
		_guard_quiet_remaining = maxf(post_upgrade_input_guard_seconds, 0.0)
		if _guard_quiet_remaining <= 0.0:
			_end_input_guard()
		return

	_guard_quiet_remaining = maxf(_guard_quiet_remaining - delta, 0.0)
	if _guard_quiet_remaining <= 0.0:
		_end_input_guard()

func _physics_process(_delta: float) -> void:
	if authored_layout_enabled and not is_authored_layout_valid():
		return
	if player == null or not is_instance_valid(player) or player.is_dead:
		return
	if player.global_position.y > 760.0:
		player.reset_to_spawn(_get_player_spawn_position())

func is_gameplay_action_blocked(action: StringName) -> bool:
	if authored_layout_enabled and not is_authored_layout_valid():
		return true
	if _door_request_pending or _transition_in_progress or is_instance_valid(_transition_overlay):
		return true
	if not DISCRETE_INPUT_ACTIONS.has(action):
		return false
	if _upgrade_flow_state in [
		UpgradeFlowState.VICTORY_PENDING,
		UpgradeFlowState.OFFER_OPEN,
		UpgradeFlowState.SELECTED,
	]:
		return true
	return _guard_active

func _on_room_cleared() -> void:
	if authored_layout_enabled and not is_authored_layout_valid():
		return
	if _upgrade_flow_state != UpgradeFlowState.INACTIVE:
		return
	_upgrade_flow_state = UpgradeFlowState.VICTORY_PENDING
	if player != null and is_instance_valid(player):
		player.ball_launcher.request_stop_active_sweep()
	_queue_post_flush_resolution()

func _on_player_died() -> void:
	_cancel_standalone_transition()
	_death_pending = true
	_upgrade_flow_state = UpgradeFlowState.CANCELLED
	if player != null and is_instance_valid(player):
		player.ball_launcher.request_stop_active_sweep()
	_queue_post_flush_resolution()

func _queue_post_flush_resolution() -> void:
	if _post_flush_resolution_queued:
		return
	_post_flush_resolution_queued = true
	call_deferred("_resolve_after_physics_flush")

func _resolve_after_physics_flush() -> void:
	if authored_layout_enabled and not is_authored_layout_valid():
		_post_flush_resolution_queued = false
		return
	_post_flush_resolution_queued = false
	if player != null and is_instance_valid(player):
		player.ball_launcher.cleanup_active_ball_after_flush()
	combat_room.cleanup_hostile_projectiles_after_flush()
	combat_room.refresh_status_after_physics()

	if _death_pending or player == null or not is_instance_valid(player) or player.is_dead:
		_death_pending = true
		_upgrade_flow_state = UpgradeFlowState.CANCELLED
		_transition_in_progress = false
		run_build.clear()
		RoomTransition.clear_pending_snapshot()
		_offered_upgrade_ids.clear()
		if _upgrade_offer != null and is_instance_valid(_upgrade_offer):
			_upgrade_offer.close_offer()
		if exit_door != null:
			exit_door.call("set_room_cleared", false)
		_close_owned_offer_pause()
		_end_input_guard()
		_update_build_status()
		if player != null and is_instance_valid(player):
			player.finish_death_after_physics()
		return

	if _upgrade_flow_state != UpgradeFlowState.VICTORY_PENDING or not combat_room.room_is_cleared:
		return
	if reward_enabled and run_build.total_count() == 0:
		_open_upgrade_offer()
	else:
		_release_exit_or_complete()

func _open_upgrade_offer() -> void:
	if _upgrade_offer == null or not is_instance_valid(_upgrade_offer):
		_upgrade_flow_state = UpgradeFlowState.CANCELLED
		push_error("Main: não foi possível criar a oferta de upgrades.")
		if _run_controller_managed:
			_release_exit_or_complete()
		return
	_offered_upgrade_ids.clear()
	for definition in _upgrade_definitions:
		_offered_upgrade_ids.append(definition.upgrade_id)
	if not _upgrade_offer.present_options(_upgrade_definitions):
		_offered_upgrade_ids.clear()
		_upgrade_flow_state = UpgradeFlowState.CANCELLED
		push_error("Main: definições inválidas para a oferta.")
		if _run_controller_managed:
			_release_exit_or_complete()
		return

	_owned_offer_pause = not get_tree().paused
	_upgrade_flow_state = UpgradeFlowState.OFFER_OPEN
	if _owned_offer_pause:
		get_tree().paused = true

func _on_upgrade_selected(upgrade_id: StringName) -> void:
	if _upgrade_flow_state != UpgradeFlowState.OFFER_OPEN:
		return
	if player == null or not is_instance_valid(player) or player.is_dead:
		return
	if not _offered_upgrade_ids.has(upgrade_id):
		return
	if not RunBuild.is_known_upgrade_id(upgrade_id):
		return
	if run_build.count_for(upgrade_id) != 0 or run_build.total_count() >= RunBuild.MAX_UPGRADES:
		return

	# State changes before the build and player configurations are mutated.
	_upgrade_flow_state = UpgradeFlowState.SELECTED
	if not run_build.add_upgrade(upgrade_id):
		_upgrade_flow_state = UpgradeFlowState.OFFER_OPEN
		return
	player.apply_run_build(run_build)
	_update_build_status()
	_offered_upgrade_ids.clear()
	if _upgrade_offer != null and is_instance_valid(_upgrade_offer):
		_upgrade_offer.close_offer()
	_begin_input_guard()
	_close_owned_offer_pause()
	_release_exit_or_complete()

func _release_exit_or_complete() -> void:
	if exit_door == null:
		_upgrade_flow_state = UpgradeFlowState.COMPLETED
		return
	_upgrade_flow_state = UpgradeFlowState.EXIT_RELEASED
	_local_reward_resolved = true
	_door_unlock_pending = true
	_release_exit_door_if_ready()

func _release_exit_door_if_ready() -> void:
	if not _door_unlock_pending or _guard_active or _upgrade_flow_state != UpgradeFlowState.EXIT_RELEASED:
		return
	if not combat_room.room_is_cleared or player == null or not is_instance_valid(player) or player.is_dead:
		return
	_door_unlock_pending = false
	if not _run_controller_managed and next_room_scene_path.strip_edges().is_empty():
		_upgrade_flow_state = UpgradeFlowState.COMPLETED
		exit_door.call("set_terminal_complete")
		return
	exit_door.call("set_room_cleared", true)

func _notify_run_progression_ready() -> void:
	if not _run_controller_managed or _run_progression_notified:
		return
	_run_progression_notified = true
	run_progression_ready.emit()

func _begin_input_guard() -> void:
	_guard_active = true
	_guard_waiting_for_release = _any_discrete_input_pressed()
	_guard_quiet_remaining = 0.0 if _guard_waiting_for_release else maxf(post_upgrade_input_guard_seconds, 0.0)
	if not _guard_waiting_for_release and _guard_quiet_remaining <= 0.0:
		_end_input_guard()

func _end_input_guard() -> void:
	_guard_active = false
	_guard_waiting_for_release = false
	_guard_quiet_remaining = 0.0
	_release_exit_door_if_ready()

func _any_discrete_input_pressed() -> bool:
	for action in DISCRETE_INPUT_ACTIONS:
		if Input.is_action_pressed(action):
			return true
	return false

func _close_owned_offer_pause() -> void:
	if _owned_offer_pause and get_tree().paused:
		get_tree().paused = false
	_owned_offer_pause = false

func _on_exit_door_transition_requested(requested_player: Player) -> void:
	if _door_request_pending or _transition_in_progress or _upgrade_flow_state != UpgradeFlowState.EXIT_RELEASED:
		return

func _validate_exit_crossing_deferred(requested_player: Player, token: int) -> void:
	if token != _transition_token or not _door_request_pending:
		return

	if not failure.is_empty():
		_door_request_pending = false
		if exit_door != null and is_instance_valid(exit_door):
			exit_door.call("report_transition_failure", failure)
		if _run_controller_managed and not _death_pending and _is_current_room_source():
			_report_managed_transition_failure(failure)
		return

	var destination_scene: PackedScene
	if not _run_controller_managed:
		var destination_path := next_room_scene_path.strip_edges()

			or not destination_scene.resource_path.begins_with("res://"):
			_door_request_pending = false

	_door_request_pending = false
	_transition_in_progress = true
	_transition_source_scene = get_tree().current_scene if not _run_controller_managed else self
	_transition_player = requested_player
	_lock_player_for_transition(requested_player)
	if _run_controller_managed:
		_notify_run_progression_ready()
		return

	_transition_overlay.name = "RoomTransitionOverlay"

func _exit_crossing_validation_error(requested_player: Player) -> String:
	if _transition_in_progress or _upgrade_flow_state != UpgradeFlowState.EXIT_RELEASED:

		return ERR_INVALID_DATA

		destination_scene,
		_transition_player.current_health,

	if result != OK:
		_standalone_swap_committed = false
		RoomTransition.clear_pending_snapshot()
		return result
	return OK

func _load_current_encounter() -> void:
	if _run_ended:
		return

	var packed_scene: PackedScene = boss_room_scene if _is_boss_room() else common_room_scene
	var next_room := packed_scene.instantiate()
	# RunRoot processes while paused; room descendants must still stop with gameplay.
	next_room.process_mode = Node.PROCESS_MODE_PAUSABLE
	if not next_room.has_method("configure_run_managed"):
		next_room.free()
		_fail_run("ERRO: a cena de sala não oferece integração gerenciada.")
		return
	if not next_room.has_signal("run_progression_ready"):
		next_room.free()
		_fail_run("ERRO: a sala não oferece o sinal run_progression_ready.")
		return
	var should_offer_build_upgrade := _run_build.total_count() == 0
	if not bool(next_room.call("configure_run_managed", _run_build, should_offer_build_upgrade)):
		var layout_error := ""
		if next_room.has_method("get_authored_layout_error"):
			layout_error = String(next_room.call("get_authored_layout_error"))
		next_room.free()
		var failure_message := "ERRO: não foi possível configurar a sala para esta run."
		if not layout_error.is_empty():
			failure_message += " Layout: " + layout_error
		_fail_run(failure_message)
		return

	var progression_callback := Callable(self, "_on_room_progression_ready").bind(next_room)
	next_room.connect("run_progression_ready", progression_callback, CONNECT_ONE_SHOT)
	room_container.add_child(next_room)
	current_room_instance = next_room

	var player := _find_player(next_room)
	if player == null or player.health == null:
		_discard_current_room("ERRO: a sala não contém um jogador com PlayerHealth.")
		return

	if _run_player_health < 0:
		_run_player_health = player.current_health
		_run_player_max_health = player.maximum_health
	else:
		if _run_player_health <= 0 or _run_player_max_health <= 0:
			_discard_current_room("ERRO: HP inválido; a run não pode continuar.")
			return
		if not player.health.restore_health_for_room_transition(
			_run_player_health,
			_run_player_max_health
		):
			_discard_current_room("ERRO: não foi possível restaurar o HP da run.")
			return

	if not player.health_changed.is_connected(_on_player_health_changed):
		player.health_changed.connect(_on_player_health_changed)
	if not player.died.is_connected(_on_player_died):
		player.died.connect(_on_player_died)
	_on_player_health_changed(player.current_health, player.maximum_health)

	# Main._ready reapplies the shared RunBuild; branch modifiers are installed
	# afterward and are applied to each derived projectile config at launch.

func _advance_after_room(completed_room: Node) -> void:
	if _run_ended or completed_room != current_room_instance:
		return

	if _is_boss_room():
		var reward_screen: Variant = RewardScreenScript.new()
		if reward_screen == null:
			_fail_run("ERRO: não foi possível abrir a recompensa do chefe.")
			return
		_owned_reward_pause = not get_tree().paused
		if _owned_reward_pause:
			get_tree().paused = true
		add_child(reward_screen)
		_active_reward_screen = reward_screen
		var selected_reward: String = await reward_screen.reward_chosen
		_active_reward_screen = null
		if is_instance_valid(reward_screen):
			reward_screen.queue_free()
		_close_owned_reward_pause()
		if _run_ended or selected_reward.is_empty():
			return
		_apply_reward(selected_reward)

	if _is_final_boss():
		_run_ended = true
		_show_victory_screen()
		return

	_update_hud("SALA CONCLUÍDA. PRÓXIMA ETAPA EM %.1f s." % transition_delay)
	await get_tree().create_timer(maxf(transition_delay, 0.0)).timeout
	if _run_ended or completed_room != current_room_instance:
		return
	_owned_transition_pause = not get_tree().paused
	if _owned_transition_pause:
		get_tree().paused = true
	await _fade_managed_transition_to(1.0, 0.18)
	if _run_ended or completed_room != current_room_instance:
		_finish_managed_transition(false)
		return

	current_room_instance = null
	if is_instance_valid(completed_room):
		completed_room.queue_free()
	await get_tree().process_frame
	if _run_ended:
		_finish_managed_transition(false)
		return

	_advance_stage()
	transition_pending = false
	_load_current_encounter()
	if _run_ended:
		_update_hud("FALHA AO INICIAR A PRÓXIMA SALA")
		_show_game_over_screen("Não foi possível continuar a run.")
		_finish_managed_transition(false)
		return
	await _fade_managed_transition_to(0.0, 0.22)
	if _run_ended:
		_finish_managed_transition(false)
		return
	_finish_managed_transition(true)

## Snapshot simples e one-shot que atravessa uma troca de cena. Não persiste
## RunBuild nem qualquer Resource vivo.

const RunBuild = preload("res://scripts/progression/run_build.gd")

static var _pending_snapshot: Dictionary = {}

static func prepare_run_snapshot(
	destination_scene: PackedScene,
	current_health: Variant,
	maximum_health: Variant,
	build: RunBuild
) -> bool:
	_pending_snapshot.clear()
	if destination_scene == null or not is_instance_valid(destination_scene) or build == null:
		return false
	if typeof(current_health) != TYPE_INT or typeof(maximum_health) != TYPE_INT:
		return false

	var canonical_destination := destination_scene.resource_path
	if not _is_canonical_resource_path(canonical_destination):
		return false
	var build_data := build.to_snapshot_data()
	var snapshot := {
		"version": 1,
		"canonical_destination": canonical_destination,
		"hp_current": current_health,
		"hp_max": maximum_health,
		"upgrade_ids": build_data.get("upgrade_ids"),
		"counts_by_id": build_data.get("counts_by_id"),
	}
	if not _is_valid_snapshot(snapshot, canonical_destination):
		return false
	_pending_snapshot = snapshot.duplicate(true)
	return true

static func consume_pending_snapshot(destination_scene: PackedScene) -> Dictionary:
	if _pending_snapshot.is_empty():
		return {}
	var snapshot := _pending_snapshot.duplicate(true)
	_pending_snapshot.clear()
	if destination_scene == null or not is_instance_valid(destination_scene):
		return {}
	var canonical_destination := destination_scene.resource_path
	if not _is_canonical_resource_path(canonical_destination):
		return {}
	if not _is_valid_snapshot(snapshot, canonical_destination):
		return {}
	return snapshot.duplicate(true)

static func clear_pending_snapshot() -> void:
	_pending_snapshot.clear()

static func _is_valid_snapshot(snapshot: Variant, expected_destination: String) -> bool:
	if typeof(snapshot) != TYPE_DICTIONARY or not _is_canonical_resource_path(expected_destination):
		return false
	var required_keys: Array[String] = [
		"version",
		"canonical_destination",
		"hp_current",
		"hp_max",
		"upgrade_ids",
		"counts_by_id",
	]
	if snapshot.size() != required_keys.size():
		return false
	for key in required_keys:
		if not snapshot.has(key):
			return false
	if typeof(snapshot["version"]) != TYPE_INT or int(snapshot["version"]) != 1:
		return false
	if typeof(snapshot["canonical_destination"]) != TYPE_STRING:
		return false
	if String(snapshot["canonical_destination"]) != expected_destination:
		return false
	if typeof(snapshot["hp_current"]) != TYPE_INT or typeof(snapshot["hp_max"]) != TYPE_INT:
		return false
	var current_health := int(snapshot["hp_current"])
	var maximum_health := int(snapshot["hp_max"])
	# PlayerHealth.restore_health_for_room_transition aceita somente máximo 1..100.
	if maximum_health < 1 or maximum_health > 100 or current_health < 1 or current_health > maximum_health:
		return false
	if typeof(snapshot["upgrade_ids"]) != TYPE_ARRAY or typeof(snapshot["counts_by_id"]) != TYPE_DICTIONARY:
		return false
	for upgrade_id in snapshot["upgrade_ids"]:
		if typeof(upgrade_id) != TYPE_STRING:
			return false
	for upgrade_id in snapshot["counts_by_id"].keys():
		if typeof(upgrade_id) != TYPE_STRING:
			return false
	var validated_build := RunBuild.new()
	return validated_build.replace_state(snapshot["upgrade_ids"], snapshot["counts_by_id"])

static func _is_canonical_resource_path(path: String) -> bool:
	return path.begins_with("res://") and path.length() > "res://".length()
