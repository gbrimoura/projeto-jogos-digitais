# Plano prospectivo — contador de nível das cartas

## Objetivo
Adicionar ao rodapé existente de cada carta um status de aquisição e um contador explícito de nível atual, próximo nível e teto aplicável. O rodapé ocupa a mesma área; não aumenta cartão, fonte ou ícones.

## Decisões aprovadas para esta frente
- Manter o box atual e a moldura de 160×240.
- Linha 1: status centralizado em x=12..148, y=205..216: `NOVO` ou `EVOLUIR`; ao chegar ao teto, `NOVO - MÁXIMO` ou `EVOLUIR - MÁXIMO`.
- Linha 2: contador centralizado em x=12..148, y=217..228, no formato `NÍVEL ATUAL > PRÓXIMO / MÁXIMO`. Mostrar sempre o rank possuído antes da escolha, inclusive 0 para uma carta nova.
- Fonte bitmap atual, 5×11 glifos com avanço 6 e altura de linha 12. Para `NÍVEL 219 > 220 / 220`, 21 glifos (126 px) cabem na largura de 136 px.
- Texto de status ciano `#52BAC7`; status que chega ao teto amarelo `#D2A75C`. Prefixo, nível atual, seta e teto cinza `#B6BEC3`; somente o nível alvo fica amarelo.
- Derivar o máximo por `UpgradeCatalog.max_rank_for(upgrade_id, base_maximum_health)`. Exibir fielmente os tetos existentes: 3 para Motor/Pressão/Mola/Dínamo, teto de Chassi derivado do HP base e teto provisório 220 para Impacto/Carga.
- Prévia Aseprite: Carga 0→1/220, Mola 1→2/3 e Dínamo 2→3/3. Texto de Dínamo acompanha a comparação atual 0,3s→0,45s.

# Especificação — contador de nível e teto

## Dados
- `card_preview` continua rejeitando upgrades inválidos ou indisponíveis usando a lógica existente.
- Apresentar `rank_before`, `rank_after` e `rank_max`, sendo `rank_max` derivado de `max_rank_for(upgrade_id, base_maximum_health)`.
- Status base `NOVO` quando rank atual é 0; caso contrário `EVOLUIR`. Se o rank ofertado atingir `rank_max`, acrescentar ` - MÁXIMO`.
- O contador é sempre `NÍVEL {rank_before} > {rank_after} / {rank_max}`. É informação de apresentação; não modifica oferta nem aquisição.

## Geometria e cor
- Mantém cartão e moldura 160×240 e os controles do rodapé dentro da caixa existente.
- Status: x=12..148, y=205..216, altura 12 px, centralizado. Ciano para status normal, amarelo para status que atinge o máximo.

- Fonte bitmap atual: glifos 5×11, avanço 6 px, line-height 12 px; sem antialias.
- Comprimento máximo relevante: `NÍVEL 219 > 220 / 220` = 21 glifos = 126 px dentro de 136 px.
- Não cobrir ou reposicionar ícones, título, resumo, tópicos ou divisórias existentes.

static func max_rank_for(upgrade_id: Variant, base_maximum_health: int = 5) -> int:
	var definition := definition_for(upgrade_id)
	if definition == null:
		return 0
	var cap: int = clampi(definition.rank_cap, 0, MAX_RUN_ACQUISITIONS)
	if definition.maximum_health_per_rank > 0:
		return clampi(100 - maxi(base_maximum_health, 1), 0, cap)
	return cap


static func can_acquire(upgrade_id: Variant, current_rank: int, base_maximum_health: int = 5) -> bool:
	return is_known_upgrade_id(upgrade_id) and current_rank >= 0 \
		and current_rank < max_rank_for(upgrade_id, base_maximum_health)
