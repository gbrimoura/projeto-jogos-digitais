# Histórico e snapshots

O diretório `base/` preserva cópias byte a byte de `scripts/world/training_target.gd` e `scenes/training_target.tscn` antes de qualquer edição runtime nesta tarefa. `base/sha256-before.json` registra os hashes calculados no momento da cópia. O snapshot base é a versão Cartoon V2 já publicada.
