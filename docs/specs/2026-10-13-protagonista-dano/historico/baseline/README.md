# Baseline anterior ao hurt v1

Snapshot byte a byte capturado em 13/10/2026 antes da geração/integração de hurt. O baseline inclui as mudanças locais Dash V4, já presentes no atlas, fonte Aseprite, SpriteFrames e documentação no momento da captura. Nenhuma dessas mudanças foi editada nesta etapa.

O atlas é 1600×64 (25 frames); a fonte Aseprite é 64×64 com 25 frames. Os hashes SHA-256 e os caminhos correspondentes estão em `manifest.json`. Os arquivos runtime foram copiados para `runtime/` preservando suas subpastas.
