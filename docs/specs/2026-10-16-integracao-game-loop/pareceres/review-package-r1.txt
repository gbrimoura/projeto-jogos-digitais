## Decisões

- `RunRoot` será a cena principal e controlará a sequência de salas, o avanço de andares, as recompensas de chefe e o fim/reinício da run.
- Cada sala atual continua sendo uma instância de `scenes/main.tscn`. O controlador configura essas instâncias em modo gerenciado, removendo a porta somente daquela instância; `Main` segue responsável por vitória, parada e limpeza de projéteis, oferta `RunBuild` e proteção de entrada.
- `RunBuild` será estado compartilhado de `RunController` durante a run. A oferta existente aparece quando ainda está vazia e não se repete após uma escolha válida. O `RewardScreen` da branch permanece uma recompensa de chefe separada, com modificadores multiplicativos de dano, velocidade e raio do projétil.
- O modificador de dano multiplica a configuração final depois de aplicar `RunBuild` e arredonda para inteiro. Com a base atual de 1 de dano, `round(1 × 1,25)` continua 1; esse limite de quantização será registrado, sem inventar outro valor de balanceamento.
- A cena atual de chefe é o mesmo placeholder `main.tscn`; `run_root.tscn` configura uma run de um andar. Isso não define o GDD nem balanceamento final.
- As APIs incompatíveis da antiga implementação de jogador são adaptadas aos contratos atuais de `PlayerHealth` e `Player.take_damage(amount, source) -> bool`. O `TrainingTarget` mantém o ataque AoE 0,65/0,14/1,4 s, raio 140, dano-flash e visual Cartoon V2; o antigo contato por cooldown da branch não é combinado com a sentinela.
- O `ImpactSpark` da branch cobre o ricochete em parede; `CombatFeedback` atual continua responsável por parry e acertos aceitos, inclusive a carga. A inclusão de efeitos não altera dano, colisões ou ordem de callbacks.
- A geração aleatória atual de plataformas e o posicionamento de inimigos da `main` permanecem ativos em cada nova instância de sala.

# Especificação — integração do loop de jogo

**Data:** 16/10/2026  
**Estado:** contrato prospectivo antes da edição de runtime.

## Fluxo de execução

1. `project.godot` inicia por `res://run_root.tscn`, sem depender de UID ainda não importado.
2. `RunController` instancia a sala comum ou chefe dentro de `RoomContainer`, compartilha a instância da `RunBuild` atual e informa se a oferta local ainda deve aparecer.
3. `Main` conserva seu fluxo de vitória e limpeza pós-física. Em modo gerenciado, não consome snapshot estático de transição e remove `ExitDoor` apenas da instância corrente. Após concluir o caminho de vitória e qualquer oferta local, emite `run_progression_ready` uma vez.
4. `RunController` só avança após esse sinal. Ao trocar de encontro, preserva HP atual/máximo via `PlayerHealth.restore_health_for_room_transition`; valores de vida inválidos ou jogador morto cancelam o avanço. A instância nova aplica `RunBuild` no `_ready` e recebe os multiplicadores da run depois que os filhos terminaram de inicializar.
5. Uma recompensa de chefe aguarda seleção ou cancelamento por morte antes de alterar multiplicadores. A morte também invalida temporizadores/continuações pendentes, mostra Game Over e permite reinício.
6. Modificadores de projétil são aplicados ao snapshot derivado em `BallLauncher`, depois dos efeitos tipados de `RunBuild`; nunca mutam cumulativamente o Resource-base.

## Contratos preservados

- Player continua usando `PlayerHealth` como fonte única de HP, invulnerabilidade e morte; dano retorna booleano.
- `Main` standalone continua usando oferta `RunBuild`, porta, snapshot one-shot e destinos atuais sem alterações de semântica.
- A integração gerenciada mantém ataque circular da sentinela, flash de dano e animações/arte Cartoon V2, incluindo sincronização do aviso visual, physics query e LOS existentes.
- O estado físico da bola mantém charge, parada de sweep em callbacks letais e lock de liberação do parry; o clique de disparo permanece bloqueado durante swing.
- Efeitos de parede são visuais e deferred. Parry e hits aceitos permanecem nos estilos do `CombatFeedback` atual.
- Plataformas continuam usando o posicionamento aleatório existente e os inimigos mantêm suas regras atuais de posição e ataque.
- A sala de chefe atual reutiliza `main.tscn` como placeholder; `floors_per_run=1` na cena é apenas a configuração desta integração.

func _ready() -> void:
	# The run controller must handle overlays and progression while gameplay is paused.
	process_mode = Node.PROCESS_MODE_ALWAYS
	RoomTransition.clear_pending_snapshot()
	if common_room_scene == null:
		_fail_run("ERRO: cena de sala comum não definida.")
		return
	if boss_room_scene == null:
		_fail_run("ERRO: cena de chefe não definida.")
		return
	_load_current_encounter()


func _is_boss_room() -> bool:
	return current_room > common_rooms_per_floor


func _is_final_boss() -> bool:
	return current_floor == floors_per_run and _is_boss_room()


func _load_current_encounter() -> void:
	if _run_ended:
		return

	var packed_scene: PackedScene = boss_room_scene if _is_boss_room() else common_room_scene
	var next_room := packed_scene.instantiate()
	# RunRoot processes while paused; room descendants must still stop with gameplay.
	next_room.process_mode = Node.PROCESS_MODE_PAUSABLE
	if not next_room.has_method("configure_run_managed"):
		next_room.free()
		_fail_run("ERRO: a cena de sala não oferece integração gerenciada.")
		return
	if not next_room.has_signal("run_progression_ready"):
		next_room.free()
		_fail_run("ERRO: a sala não oferece o sinal run_progression_ready.")
		return
	var should_offer_build_upgrade := _run_build.total_count() == 0
	if not bool(next_room.call("configure_run_managed", _run_build, should_offer_build_upgrade)):
		next_room.free()
		_fail_run("ERRO: não foi possível configurar a sala para esta run.")
		return

	var progression_callback := Callable(self, "_on_room_progression_ready").bind(next_room)
	next_room.connect("run_progression_ready", progression_callback, CONNECT_ONE_SHOT)
	room_container.add_child(next_room)
	current_room_instance = next_room

	var player := _find_player(next_room)
	if player == null or player.health == null:
		_discard_current_room("ERRO: a sala não contém um jogador com PlayerHealth.")
		return

	if _run_player_health < 0:
		_run_player_health = player.current_health
		_run_player_max_health = player.maximum_health
	else:
		if _run_player_health <= 0 or _run_player_max_health <= 0:
			_discard_current_room("ERRO: HP inválido; a run não pode continuar.")
			return
		if not player.health.restore_health_for_room_transition(
			_run_player_health,
			_run_player_max_health
		):
			_discard_current_room("ERRO: não foi possível restaurar o HP da run.")
			return

	if not player.health_changed.is_connected(_on_player_health_changed):
		player.health_changed.connect(_on_player_health_changed)
	if not player.died.is_connected(_on_player_died):
		player.died.connect(_on_player_died)
	_on_player_health_changed(player.current_health, player.maximum_health)

	# Main._ready reapplies the shared RunBuild; branch modifiers are installed
	# afterward and are applied to each derived projectile config at launch.
	_apply_run_upgrades(next_room)
	_update_hud("ENCONTRO ATIVO")


func _on_room_progression_ready(room: Node) -> void:
	if _run_ended or transition_pending or room != current_room_instance:
		return
	transition_pending = true
	call_deferred("_advance_after_room", room)


func _advance_after_room(completed_room: Node) -> void:
	if _run_ended or completed_room != current_room_instance:
		return

	if _is_boss_room():
		var reward_screen: Variant = RewardScreenScript.new()
		if reward_screen == null:
			_fail_run("ERRO: não foi possível abrir a recompensa do chefe.")
			return
		_owned_reward_pause = not get_tree().paused
		if _owned_reward_pause:
			get_tree().paused = true
		add_child(reward_screen)
		_active_reward_screen = reward_screen
		var selected_reward: String = await reward_screen.reward_chosen
		_active_reward_screen = null
		if is_instance_valid(reward_screen):
			reward_screen.queue_free()
		_close_owned_reward_pause()
		if _run_ended or selected_reward.is_empty():
			return
		_apply_reward(selected_reward)

	if _is_final_boss():
		_run_ended = true
		_show_victory_screen()
		return

	_update_hud("SALA CONCLUÍDA. PRÓXIMA ETAPA EM %.1f s." % transition_delay)
	await get_tree().create_timer(maxf(transition_delay, 0.0)).timeout
	if _run_ended or completed_room != current_room_instance:
		return

	current_room_instance = null
	if is_instance_valid(completed_room):
		completed_room.queue_free()
	await get_tree().process_frame
	if _run_ended:
		return

	_advance_stage()
	transition_pending = false
	_load_current_encounter()


func _advance_stage() -> void:
	if _is_boss_room():
		current_floor += 1
		current_room = 1
	else:
		current_room += 1

	set_process_input(true)
	if not combat_room.room_cleared.is_connected(_on_room_cleared):
		combat_room.room_cleared.connect(_on_room_cleared)
	if player != null and not player.died.is_connected(_on_player_died):
		player.died.connect(_on_player_died)
	if exit_door != null:
		var transition_callback := Callable(self, "_on_exit_door_transition_requested")
		if not exit_door.is_connected("transition_requested", transition_callback):
			exit_door.connect("transition_requested", transition_callback)

	var title_label := get_node_or_null(room_title_label_path) as Label
	if title_label != null:
		title_label.text = room_title

		player.reset_to_spawn(_get_player_spawn_position())

	# entre encontros; cenas standalone continuam consumindo o snapshot one-shot.
	var incoming_snapshot: Dictionary = {}
	if not _run_controller_managed:
		incoming_snapshot = RoomTransition.consume_pending_snapshot(_load_current_packed_scene())
	if _run_controller_managed and _managed_run_build != null:

				var health_restored := player.health.restore_health_for_room_transition(
					int(incoming_snapshot["hp_current"]),
					int(incoming_snapshot["hp_max"])
				)
				if health_restored:
					run_build = restored_build
		player.apply_run_build(run_build)

	_upgrade_offer = UpgradeOfferScene.instantiate() as UpgradeOffer
	if _upgrade_offer != null:
		add_child(_upgrade_offer)
		_upgrade_offer.upgrade_selected.connect(_on_upgrade_selected)
		_upgrade_offer.hide()

	_update_build_status()
	if exit_door != null:
		exit_door.call("set_room_cleared", false)
	if combat_room.room_is_cleared:
		_on_room_cleared()

func _exit_tree() -> void:
	if _upgrade_offer != null and is_instance_valid(_upgrade_offer):
		_upgrade_offer.close_offer()
	_guard_active = false
	_guard_waiting_for_release = false
	_guard_quiet_remaining = 0.0
	# Do not unpause during teardown; the new room inherits the actual tree state.
	_owned_offer_pause = false

func _input(event: InputEvent) -> void:
	if _upgrade_flow_state == UpgradeFlowState.OFFER_OPEN and event.is_action_pressed("interact"):
		get_viewport().set_input_as_handled()
		return
	if not _guard_active:
		return
	for action in DISCRETE_INPUT_ACTIONS:
		if event.is_action_pressed(action):
			_guard_waiting_for_release = true
			_guard_quiet_remaining = 0.0
			get_viewport().set_input_as_handled()
			return

func _process(delta: float) -> void:
	if not _guard_active:
		return
	if _any_discrete_input_pressed():
		_guard_waiting_for_release = true
		_guard_quiet_remaining = 0.0
		return
	if _guard_waiting_for_release:
		_guard_waiting_for_release = false
		_guard_quiet_remaining = maxf(post_upgrade_input_guard_seconds, 0.0)
		if _guard_quiet_remaining <= 0.0:
			_end_input_guard()
		return

	_guard_quiet_remaining = maxf(_guard_quiet_remaining - delta, 0.0)
	if _guard_quiet_remaining <= 0.0:
		_end_input_guard()

	if player == null or not is_instance_valid(player) or player.is_dead:
		return

		player.reset_to_spawn(_get_player_spawn_position())

func get_spawn_position_for_direction(direction: Vector2) -> Vector2:
	if _shot_origin == null or projectile_config == null:
		return Vector2.INF

	var launch_direction := direction.normalized()
	if launch_direction.is_zero_approx():
		launch_direction = Vector2.RIGHT

	var config := projectile_config
	_ensure_spawn_query(config)
	var space_state := _shot_origin.get_world_2d().direct_space_state
	var origin := _shot_origin.global_position
	if not _is_spawn_position_clear(space_state, origin):
		return Vector2.INF

	var requested_distance := maxf(config.spawn_offset, 0.0)
	if requested_distance <= 0.0:
		return origin

	var motion := launch_direction * requested_distance
	_spawn_query.transform = Transform2D(0.0, origin)
	_spawn_query.motion = motion
	var fractions := space_state.cast_motion(_spawn_query)
	if fractions.size() < 2:
		return Vector2.INF

	var safe_fraction := clampf(fractions[0], 0.0, 1.0)
	var spawn_distance := requested_distance * safe_fraction
	if safe_fraction < 1.0:
		spawn_distance = maxf(spawn_distance - maxf(config.collision_skin, 0.0), 0.0)

	var candidate := origin + launch_direction * spawn_distance
	if not _is_spawn_position_clear(space_state, candidate):
		var low := 0.0
		var high := spawn_distance
		for _attempt in range(8):
			var midpoint := (low + high) * 0.5
			if _is_spawn_position_clear(space_state, origin + launch_direction * midpoint):
				low = midpoint
			else:
				high = midpoint
		spawn_distance = low
		candidate = origin + launch_direction * spawn_distance

	if spawn_distance <= 0.01:
		return Vector2.INF
	return candidate

func _ensure_spawn_query(config: ProjectileConfig) -> void:
	if _spawn_shape == null:

	if _spawn_query == null:
		_spawn_query = PhysicsShapeQueryParameters2D.new()
		_spawn_query.shape = _spawn_shape
		_spawn_query.collide_with_bodies = true
		_spawn_query.collide_with_areas = false

	_spawn_shape.radius = config.collision_radius
	_spawn_query.collision_mask = config.collision_mask
	_spawn_query.margin = maxf(config.collision_safe_margin, 0.01)

	_spawn_query.transform = Transform2D(0.0, position)
	_spawn_query.motion = Vector2.ZERO
	return space_state.intersect_shape(_spawn_query, 1).is_empty()

		return null
	var derived_config := _base_projectile_config.duplicate(true) as ProjectileConfig
	if _run_build != null:

			derived_config.damage = IMPACTO_REFORCADO_DEFINITION.projectile_damage_override
		if _run_build.has_upgrade(CARGA_REATIVA_DEFINITION.upgrade_id):

	# Run rewards derive from the already-upgraded copy; the base Resource stays unchanged.
	derived_config.damage = maxi(roundi(float(derived_config.damage) * _run_damage_multiplier), 1)
	derived_config.speed *= _run_speed_multiplier
	derived_config.collision_radius *= _run_radius_multiplier
	return derived_config

func _physics_process(delta: float) -> void:
	if not _has_launched or _has_finished or _stop_sweep_requested:
		return

	_damaged_targets_this_tick.clear()
	_update_parry_release_lock()

	var motion_delta := minf(delta, maxf(_lifetime_remaining, 0.0))
	var expires_after_motion := _lifetime_remaining <= delta
	_lifetime_remaining = maxf(_lifetime_remaining - delta, 0.0)

	var remaining_motion := _pending_motion + velocity * motion_delta
	_pending_motion = Vector2.ZERO
	var collisions_this_tick := 0
	var frame_elapsed: float = 0.0
	var collision_limit := maxi(_config.max_collisions_per_tick, 1)
	if expires_after_motion:
		collision_limit = maxi(collision_limit, _config.max_bounces + 4)
	var safe_margin := maxf(_config.collision_safe_margin, 0.01)

	while not _stop_sweep_requested and not remaining_motion.is_zero_approx() and collisions_this_tick < collision_limit:
		var segment_start := global_position
		var segment_distance := remaining_motion.length()
		var segment_speed := maxf(velocity.length(), 0.001)
		var segment_duration := minf(segment_distance / segment_speed, maxf(delta - frame_elapsed, 0.0))
		var parry_hit := _get_parry_hit(remaining_motion, frame_elapsed, segment_duration)
		var collision := move_and_collide(remaining_motion, false, safe_margin, false)
		var world_fraction: float = 1.0
		if collision != null and segment_distance > 0.0:
			world_fraction = clampf(collision.get_travel().length() / segment_distance, 0.0, 1.0)

		if not parry_hit.is_empty():
			var parry_fraction := float(parry_hit.get("fraction", INF))
			var parry_precedes_world := collision == null or parry_fraction < world_fraction - 0.00001
			if parry_precedes_world:
				var parry_position := segment_start + remaining_motion * parry_fraction
				var parry_scene_root := get_tree().current_scene
				global_position = parry_position
				velocity = Vector2(parry_hit.get("direction", Vector2.ZERO)).normalized() * _config.speed
				if velocity.is_zero_approx():
					velocity = Vector2.RIGHT * _config.speed
				_last_parry_swing_id = int(parry_hit.get("swing_id", -1))
				_parry_release_pending = true
				CombatFeedbackScript.enqueue(
					parry_scene_root,
					parry_position,
					CombatFeedbackScript.EffectKind.PARRY
				)
				_arm_reactive_charge()
				_notify_parry_success(_last_parry_swing_id)
				if _has_finished or _stop_sweep_requested:
					return
				_pending_motion = Vector2.ZERO
				frame_elapsed = minf(frame_elapsed + segment_duration * parry_fraction, delta)
				remaining_motion = velocity.normalized() * segment_distance * (1.0 - parry_fraction)
				continue

		if collision == null:
			if expires_after_motion:
				_finish("lifetime")
			return

		collisions_this_tick += 1
		frame_elapsed = minf(frame_elapsed + collision.get_travel().length() / segment_speed, delta)
		var surface_normal := collision.get_normal().normalized()
		if surface_normal.is_zero_approx():
			_finish("invalid_collision")
			return

		if not BounceResolver.should_bounce(velocity, surface_normal):
			global_position += surface_normal * _config.collision_skin
			velocity = BounceResolver.slide_velocity(velocity, surface_normal, _config.speed)
			var grazing_remainder := collision.get_remainder()
			if grazing_remainder.is_zero_approx() or velocity.is_zero_approx():
				if expires_after_motion:
					_finish("lifetime")
				return
			remaining_motion = velocity.normalized() * grazing_remainder.length()
			continue

		var next_bounce_index := _bounce_count + 1
		if next_bounce_index > _config.max_bounces:
			_finish("bounce_limit")
			return

		_bounce_count = next_bounce_index
		velocity = BounceResolver.reflect_velocity(velocity, surface_normal, _config.speed)
		var impact_position := collision.get_position()
		var impact_scene_root := get_tree().current_scene
		var collider := collision.get_collider()
		global_position += surface_normal * _config.collision_skin
		_apply_impact_damage(collider, impact_position, impact_scene_root)
		if _has_finished or _stop_sweep_requested:
			return
		if not _is_damageable_collider(collider):
			_enqueue_wall_spark(impact_scene_root, impact_position)
		bounced.emit(_bounce_count, impact_position, surface_normal)
		if _has_finished or _stop_sweep_requested:
			return

		var remainder := collision.get_remainder()
		if remainder.is_zero_approx() or velocity.is_zero_approx():
			if expires_after_motion:
				_finish("lifetime")
			return
		remaining_motion = velocity.normalized() * remainder.length()

	if not remaining_motion.is_zero_approx():
		if expires_after_motion:
			_finish("lifetime")
		else:
			_pending_motion = remaining_motion
	elif expires_after_motion:
		_finish("lifetime")

func _apply_impact_damage(collider: Object, impact_position: Vector2, feedback_scene_root: Node) -> void:
	if _config == null or _config.damage <= 0 or not collider is Node:
		return

	var target := collider as Node
	if not target.is_in_group("damageable") or not target.has_method("take_damage"):
		return
	if _damaged_targets_this_tick.has(target):
		return

	_damaged_targets_this_tick[target] = true
	var was_charged := _charge_state == ChargeState.CHARGED
	var damage_amount := _config.damage
	if was_charged:
		damage_amount += maxi(_config.charged_damage_bonus, 0)

	var damage_was_accepted := typeof(damage_result) == TYPE_BOOL and bool(damage_result)
	if not damage_was_accepted:
		return

		CombatFeedbackScript.EffectKind.CHARGED_HIT
		if was_charged
		else CombatFeedbackScript.EffectKind.ENEMY_HIT
	)
	CombatFeedbackScript.enqueue(feedback_scene_root, impact_position, effect_kind)
	if was_charged and _charge_state == ChargeState.CHARGED:
		_set_charge_state(ChargeState.CONSUMED)

	_clear_counts()

func add_upgrade(upgrade_id: StringName) -> bool:
	if not is_known_upgrade_id(upgrade_id) or total_count() >= MAX_UPGRADES:
		return false
	if int(_counts_by_id.get(upgrade_id, 0)) != 0:
		return false
	_counts_by_id[upgrade_id] = 1
	return true

func has_upgrade(upgrade_id: StringName) -> bool:
	return is_known_upgrade_id(upgrade_id) and int(_counts_by_id.get(upgrade_id, 0)) == 1

func count_for(upgrade_id: StringName) -> int:
	return int(_counts_by_id.get(upgrade_id, 0)) if is_known_upgrade_id(upgrade_id) else 0

func total_count() -> int:
	var total := 0
	for upgrade_id in known_upgrade_ids():
		total += int(_counts_by_id.get(upgrade_id, 0))
	return total

func get_upgrade_ids() -> Array[StringName]:
	var result: Array[StringName] = []
	for upgrade_id in known_upgrade_ids():
		if int(_counts_by_id.get(upgrade_id, 0)) == 1:
			result.append(upgrade_id)
	return result

func replace_state(upgrade_ids: Variant, counts_by_id: Variant) -> bool:
	if typeof(upgrade_ids) != TYPE_ARRAY or typeof(counts_by_id) != TYPE_DICTIONARY:
		return false

	var normalized_ids: Array[StringName] = []
	for raw_id in upgrade_ids:
		if typeof(raw_id) != TYPE_STRING and typeof(raw_id) != TYPE_STRING_NAME:
			return false
		var upgrade_id := StringName(raw_id)
		if not is_known_upgrade_id(upgrade_id) or normalized_ids.has(upgrade_id):
			return false
		normalized_ids.append(upgrade_id)
		if normalized_ids.size() > MAX_UPGRADES:
			return false

	var normalized_counts: Dictionary = {}
	var seen_count_ids: Dictionary = {}
	for upgrade_id in known_upgrade_ids():
		normalized_counts[upgrade_id] = 0

	for raw_id in counts_by_id.keys():
		if typeof(raw_id) != TYPE_STRING and typeof(raw_id) != TYPE_STRING_NAME:
			return false
		var upgrade_id := StringName(raw_id)
		if not is_known_upgrade_id(upgrade_id):
			return false
		if seen_count_ids.has(upgrade_id):
			return false
		var count: Variant = counts_by_id[raw_id]
		if typeof(count) != TYPE_INT or int(count) < 0 or int(count) > 1:
			return false
		seen_count_ids[upgrade_id] = true
		normalized_counts[upgrade_id] = int(count)

	var ids_from_counts: Array[StringName] = []
	for upgrade_id in known_upgrade_ids():
		if int(normalized_counts[upgrade_id]) == 1:
			ids_from_counts.append(upgrade_id)
	if ids_from_counts.size() > MAX_UPGRADES or ids_from_counts.size() != normalized_ids.size():
		return false
	for upgrade_id in normalized_ids:
		if not ids_from_counts.has(upgrade_id):
			return false

	_counts_by_id = normalized_counts
	return true

func to_snapshot_data() -> Dictionary:
	var id_strings: Array[String] = []
	var counts: Dictionary = {}
	for upgrade_id in known_upgrade_ids():
		var count := int(_counts_by_id.get(upgrade_id, 0))
		counts[String(upgrade_id)] = count
		if count == 1:
			id_strings.append(String(upgrade_id))
	return {
		"upgrade_ids": id_strings,
		"counts_by_id": counts,
	}

func clear() -> void:
	_clear_counts()

static func is_known_upgrade_id(upgrade_id: Variant) -> bool:
	if typeof(upgrade_id) != TYPE_STRING and typeof(upgrade_id) != TYPE_STRING_NAME:
		return false
	match String(upgrade_id):
		"impacto_reforcado", "motor_acelerado", "carga_reativa":
			return true
	return false

static func known_upgrade_ids() -> Array[StringName]:
	return [IMPACTO_REFORCADO, MOTOR_ACELERADO, CARGA_REATIVA]

func _clear_counts() -> void:
	_counts_by_id.clear()
	for upgrade_id in known_upgrade_ids():
		_counts_by_id[upgrade_id] = 0

static var _pending_snapshot: Dictionary = {}

static func prepare_run_snapshot(
	destination_scene: PackedScene,
	current_health: Variant,
	maximum_health: Variant,
	build: RunBuild
) -> bool:
	_pending_snapshot.clear()
	if destination_scene == null or not is_instance_valid(destination_scene) or build == null:
		return false
	if typeof(current_health) != TYPE_INT or typeof(maximum_health) != TYPE_INT:
		return false

	var canonical_destination := destination_scene.resource_path
	if not _is_canonical_resource_path(canonical_destination):
		return false
	var build_data := build.to_snapshot_data()
	var snapshot := {
		"version": 1,
		"canonical_destination": canonical_destination,
		"hp_current": current_health,
		"hp_max": maximum_health,
		"upgrade_ids": build_data.get("upgrade_ids"),
		"counts_by_id": build_data.get("counts_by_id"),
	}
	if not _is_valid_snapshot(snapshot, canonical_destination):
		return false
	_pending_snapshot = snapshot.duplicate(true)
	return true

static func consume_pending_snapshot(destination_scene: PackedScene) -> Dictionary:
	if _pending_snapshot.is_empty():
		return {}
	var snapshot := _pending_snapshot.duplicate(true)
	_pending_snapshot.clear()
	if destination_scene == null or not is_instance_valid(destination_scene):
		return {}
	var canonical_destination := destination_scene.resource_path
	if not _is_canonical_resource_path(canonical_destination):
		return {}
	if not _is_valid_snapshot(snapshot, canonical_destination):
		return {}
	return snapshot.duplicate(true)

static func clear_pending_snapshot() -> void:
	_pending_snapshot.clear()

static func _is_valid_snapshot(snapshot: Variant, expected_destination: String) -> bool:
	if typeof(snapshot) != TYPE_DICTIONARY or not _is_canonical_resource_path(expected_destination):
		return false
	var required_keys: Array[String] = [
		"version",
		"canonical_destination",
		"hp_current",
		"hp_max",
		"upgrade_ids",
		"counts_by_id",
	]
	if snapshot.size() != required_keys.size():
		return false
	for key in required_keys:
		if not snapshot.has(key):
			return false
	if typeof(snapshot["version"]) != TYPE_INT or int(snapshot["version"]) != 1:
		return false
	if typeof(snapshot["canonical_destination"]) != TYPE_STRING:
		return false
	if String(snapshot["canonical_destination"]) != expected_destination:
		return false
	if typeof(snapshot["hp_current"]) != TYPE_INT or typeof(snapshot["hp_max"]) != TYPE_INT:
		return false
	var current_health := int(snapshot["hp_current"])
	var maximum_health := int(snapshot["hp_max"])
	# PlayerHealth.restore_health_for_room_transition aceita somente máximo 1..100.
	if maximum_health < 1 or maximum_health > 100 or current_health < 1 or current_health > maximum_health:
		return false
	if typeof(snapshot["upgrade_ids"]) != TYPE_ARRAY or typeof(snapshot["counts_by_id"]) != TYPE_DICTIONARY:
		return false
	for upgrade_id in snapshot["upgrade_ids"]:
		if typeof(upgrade_id) != TYPE_STRING:
			return false
	for upgrade_id in snapshot["counts_by_id"].keys():
		if typeof(upgrade_id) != TYPE_STRING:
			return false
	var validated_build := RunBuild.new()
	return validated_build.replace_state(snapshot["upgrade_ids"], snapshot["counts_by_id"])

static func _is_canonical_resource_path(path: String) -> bool:
	return path.begins_with("res://") and path.length() > "res://".length()

	_state_remaining = maxf(_state_remaining - delta, 0.0)
	if _state_remaining <= 0.0:
		var overshoot := maxf(delta - before_step, 0.0)
		_enter_active()
		_apply_attack_area()
		if overshoot >= maxf(active_window, 0.05):
			_enter_recovery()
		else:
			_state_remaining = maxf(active_window, 0.05) - overshoot
		return
	_update_attack_area_visual()

func _enter_active() -> void:
	_attack_state = AttackState.ACTIVE
	_state_remaining = maxf(active_window, 0.05)
	_update_attack_area_visual()

func _update_active(delta: float) -> void:
	_apply_attack_area()
	_state_remaining = maxf(_state_remaining - delta, 0.0)
	if _state_remaining <= 0.0:
		_enter_recovery()

func _apply_attack_area() -> void:
	if _defeated_emitted or _attack_state != AttackState.ACTIVE:
		return
	var overlaps: Array[Dictionary] = _find_overlaps_at_locked_center()
	for overlap in overlaps:
		var collider: Variant = overlap.get("collider")
		if not collider is PhysicsBody2D:
			continue
		var player_body := collider as PhysicsBody2D
		if not _is_alive_player(player_body):
			continue
		var player_id := player_body.get_instance_id()
		if _damaged_player_ids.has(player_id):
			continue
		if not _has_clear_line_of_sight(player_body, _locked_attack_center):
			continue
		_damaged_player_ids[player_id] = true
		var damage_result: Variant = player_body.call(
			"take_damage",
			maxi(attack_damage, 1),
			self
		)
		if typeof(damage_result) == TYPE_BOOL and bool(damage_result):

	_attack_state = AttackState.RECOVERY
	_state_remaining = maxf(recovery_duration, 0.05)
	_recovery_fade_remaining = maxf(recovery_fade_duration, 0.0)

func _update_recovery(delta: float) -> void:

	_recovery_fade_remaining = maxf(_recovery_fade_remaining - delta, 0.0)
	_update_attack_area_visual()
	if _state_remaining <= 0.0:
		_attack_state = AttackState.IDLE
		_state_remaining = 0.0
		_recovery_fade_remaining = 0.0
		_locked_player = null
		_damaged_player_ids.clear()
		_set_attack_visual(&"hidden", 0.0)
		_update_visuals()

func _update_attack_area_visual() -> void:

		AttackState.WINDUP:
			var windup_progress := 1.0 - clampf(
				_state_remaining / maxf(windup_duration, 0.05),
				0.0,
				1.0
			)
			_set_attack_visual(&"windup", 0.58 + windup_progress * 0.34)
		AttackState.ACTIVE:
			_set_attack_visual(&"active", 1.0)
		AttackState.RECOVERY:
			var fade_alpha := 0.0
			if recovery_fade_duration > 0.0:
				fade_alpha = _recovery_fade_remaining / recovery_fade_duration
			_set_attack_visual(&"recovery", clampf(fade_alpha, 0.0, 1.0))
		_:
			_set_attack_visual(&"hidden", 0.0)

		return
	_attack_visual.call(
		"set_area_state",
		_effective_attack_radius(),
		attack_center_offset if _attack_state == AttackState.IDLE else _locked_attack_center - global_position,
		phase,
		alpha
	)

func _update_hit_flash(delta: float) -> void:
	if _flash_remaining <= 0.0:
		return
	_flash_remaining = maxf(_flash_remaining - maxf(delta, 0.0), 0.0)
	_update_visuals()

func _update_visuals() -> void:
	if not is_instance_valid(_body_sprite) or not is_instance_valid(_health_fill):
		return
	var desired_animation: StringName = &"impact" if _flash_remaining > 0.0 or _attack_state == AttackState.ACTIVE else &"idle"

func _place_on_platform() -> void:
	_placement_pending = false
	var body := _get_collision_rect()
	var needed_width := body.size.x + edge_margin * 2.0

	# Prefere plataformas livres; o Floor só entra se não sobrar nenhuma,
	# e plataformas já ocupadas por outro inimigo ficam por último.
	var free: Array[SolidPlatform] = []
	var floors: Array[SolidPlatform] = []
	var taken: Array[SolidPlatform] = []
	for node in get_tree().get_nodes_in_group(&"solid_platform"):
		var candidate := node as SolidPlatform
		if candidate == null or candidate.size.x < needed_width:
			continue
		if candidate.name == &"Floor":
			floors.append(candidate)
		elif candidate.has_meta(CLAIMED_META):
			taken.append(candidate)
		else:
			free.append(candidate)

	var pool: Array[SolidPlatform] = free
	if pool.is_empty():
		pool = floors
	if pool.is_empty():
		pool = taken
	if pool.is_empty():
		push_warning("%s: nenhuma plataforma larga o bastante; mantendo a posição original." % name)
		return

	var rng := RandomNumberGenerator.new()
	if SolidPlatform.room_seed == 0:
		rng.randomize()
	else:
		rng.seed = hash([SolidPlatform.room_seed, get_index(), "training_target"])

	var platform := pool[rng.randi_range(0, pool.size() - 1)]
	platform.set_meta(CLAIMED_META, true)

	var platform_left := platform.global_position.x - platform.size.x * 0.5
	var platform_right := platform.global_position.x + platform.size.x * 0.5
	var platform_top := platform.global_position.y - platform.size.y * 0.5

	# Mantém a colisão do inimigo inteira sobre a plataforma, com a base tocando o topo.
	var min_x := platform_left + edge_margin - body.position.x
	var max_x := platform_right - edge_margin - body.end.x
	global_position = Vector2(rng.randf_range(min_x, max_x), platform_top - body.end.y)
